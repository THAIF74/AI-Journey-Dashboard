# AI Journey Dashboard

A personal dashboard I built to track my journey toward becoming an AI Engineer.

## Features

- Learning tracker
- Project tracker
- AI Ideas Vault
- Daily study tracker
- SQLite database storage
- Interactive Tkinter GUI

## Technologies Used

- Python
- Tkinter
- SQLite
- Git
- GitHub

## Project Goal

The goal of this project is to build a personal system for tracking my learning, projects, ideas, and progress while developing my skills toward AI Engineering.
